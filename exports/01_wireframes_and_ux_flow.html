03

Non-Negotiable Product Design Laws

1. Persistent Artifacts

Every feature must produce a durable record. Outings create Outing Records; profiles produce Friendship DNA; post-outing feedback yields a Rhythm Record.

2. No Marketplace / Dating Mechanics

No swiping. No hot-or-not. No raw match percentages (e.g. "98%"). Compatibility is expressed through human-readable shapes and behavioral mechanisms.

3. Always Show Friction

Every match explanation and bond analysis must include an honest "Where you might rub" section. A match with only positives is a bug.

4. Hard 6-Person Outing Cap

Free-tier outings are capped at 6 participants including the host. Enforced in database schema triggers, API endpoints, and user interfaces.
